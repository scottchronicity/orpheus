# Orpheus Crow Detection Agent

Crow vocalization detection agent using crow-tools classifier models (AVES embedder + multi-task classifier).

## Overview

Subscribes to audio motion events from `orpheus-agent-audio-motion` and performs crow vocalization detection using the crow-tools deep learning models. The system uses a two-stage pipeline:

1. **AVES Embedder**: Generates 768-dimensional embeddings from 16kHz audio
2. **Multi-task Classifier**: Classifies embeddings for species, call type, and quality

Publishes detection events to MQTT and stores results in DetectionDB.

## Features

- **Real crow-tools Integration**: Uses AVES-base-bio and multi-task classifier models
- **Species Detection**: Identifies American Crow, Fish Crow, Northwestern Crow
- **Call Type Classification**: Recognizes caw, rattle, coo, and other vocalizations
- **Quality Filtering**: Configurable quality threshold for valid detections
- **MQTT-based**: Publishes detection events for downstream consumers
- **DetectionDB Storage**: Persists all detections to SQLite database

## Audio Processing Requirements

⚠️ **Critical Sample Rates**:

- **AVES Embedder**: Requires 16kHz audio
- **Classifier**: Expects 768-dimensional embeddings (generated by AVES from 16kHz audio)
- Audio is automatically resampled from motion detection clips (typically 48kHz)

## Installation

```bash
# Install dependencies
make install

# Install systemd service
sudo make install-service
```

## Configuration

Edit `/path/to/orpheus.yaml`:

```yaml
crow_detection:
  enabled: true
  quality_threshold: 0.5
  embedder_model_path: "/data/orpheus/models/aves-base-bio.pt"
  classifier_model_path: "/data/orpheus/models/mt_70.pt"
  embedder_sample_rate: 16000
```

## Model Files

Place model files in `/data/orpheus/models/`:

- `aves-base-bio.pt` - AVES embedder model (16kHz input)
- `mt_70.pt` - Multi-task classifier model

## MQTT Topics

**Subscribes to:**

| Topic | Description |
| --- | --- |
| `orpheus/audio/motion/events` | Audio motion events from orpheus-agent-audio-motion |

### Input Event (`orpheus/audio/motion/events`)

```json
{
  "event_id": "audio_motion_20251205_091228_ch2",
  "timestamp": "2025-12-05T09:12:28.000000+00:00",
  "channel_id": "2",
  "audio_clip_path": "/data/orpheus/audio/motion/2025-12-05/channel_2/event_20251205_091228.flac",
  "detection_type": "audio.motion"
}
```

**Publishes to:**

| Topic | Description |
| --- | --- |
| `orpheus/detection/crow/events` | Crow vocalization detection results |
| `orpheus/system/crow-detection/health` | Agent liveness and statistics |

## Architecture

```bash
Audio Motion Event
        ↓
  Load Audio File (48kHz)
        ↓
  Resample to 16kHz
        ↓
  AVES Embedder → 768-d embedding
        ↓
  Multi-task Classifier
        ↓
  [Species, Call Type, Quality]
        ↓
   Publish + Store
```

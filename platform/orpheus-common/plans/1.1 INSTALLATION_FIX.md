# Installation Fix - Python 3.9.5 Compatibility

**Problem:** Original package used only `pyproject.toml` which doesn't work with old pip versions.

**Solution:** Added `setup.py` + `requirements.txt` for compatibility.

---

## What Changed

✅ **Added:** `setup.py` - For old pip compatibility  
✅ **Added:** `requirements.txt` - List of dependencies  
✅ **Added:** `requirements-dev.txt` - Development dependencies  
✅ **Added:** `Makefile` - Easy installation commands  
✅ **Added:** `INSTALL.md` - Simple installation guide  
✅ **Updated:** `pyproject.toml` - Notes setup.py takes precedence  
✅ **Updated:** `README.md` - Installation instructions  

---

## Correct Installation (Works with Python 3.9.5)

```bash
cd platform/orpheus-common

# Option 1: Use Makefile (recommended)
make install

# Option 2: Manual install
pip install -r requirements.txt
pip install -e .
```

---

## Why This Matters

**Your pip version:** 21.1.1 (from Python 3.9.5)  
**Problem:** Old pip needs `setup.py` for editable installs  
**Modern pip:** (22.0+) can use `pyproject.toml` alone

**Solution:** We now support both:
- Old pip (21.x) uses `setup.py` + `requirements.txt`
- New pip (22+) can use either approach
- Python 3.9.5 fully supported



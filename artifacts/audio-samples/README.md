# Audio Samples

Reference audio recordings for testing and calibration.

## Purpose

- Test audio clips
- Species reference calls
- Ambient noise profiles
- Calibration tones

## Formats

- WAV (*.wav) - Uncompressed
- FLAC (*.flac) - Lossless compression
- OGG (*.ogg) - Compressed audio container

# Artifacts

Stored models, recordings, and calibration data.

## Overview

Large binary files tracked with Git LFS:

- Trained ML models
- Audio samples and recordings
- Calibration data
- Test datasets

## Structure

- `models/` - Trained neural network models
- `audio-samples/` - Reference audio recordings
- `calibration/` - Hardware calibration data

## Storage

Files in this directory are managed by Git LFS to keep the repository size manageable.
